# E 部分正式测试集 v3

本次替换 E-013、E-014、E-031、E-045、E-048、E-058 和 E-059。其余 53 张图片与 v2 字节一致。所有图片仍为 768 × 768 RGB JPEG，案例编号、预期动作、参考答案及追问脚本沿用 v2。

- E-013：一张揉成团的 A4 办公纸，表现准备丢弃的纸张。
- E-014：落叶中丢弃的打印纸。
- E-031：丢弃在草木间的空塑料杯。
- E-045：用完后空置的鳀鱼食品玻璃罐。
- E-048：废弃物容器里的果蔬皮和变质食物。
- E-058：丢弃在地面的旧鞋。
- E-059：丢弃在沥青地面的已使用喷雾罐，仍用于测试超出规则范围的回复。

在 data/formal_cases.csv 查案例，照片在 photos/。data/photo_provenance.csv 保存作者、许可、来源和文件校验值，data/image_quality_audit.csv 保存尺寸及变更记录。替换的 7 条案例标记为待 A 复核。

results/ 是结构化输入下的规则一致性结果。视觉对照实验应使用同一份 v3 图片，通过 evaluate_systems.py 接入两版系统。复现规则层结果可运行 python analyze_rules.py，依赖见 requirements.txt。
