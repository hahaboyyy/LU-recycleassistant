**成员成果与整合版本**

| 角色 | 纳入复现包的成果 |
|---|---|
| A | Rules 1.0.0、16 个物品 ID、开发案例和照片出处。 |
| B | 视觉 API 调用、图片预处理、结构化识别、基线和模块测试。 |

项目的 module_c.py 基于成员提交的 Module_C(1).py 修订。F 加入结合候选的回答匹配、否定与不确定处理、纸巾和办公纸的明确选择、完整回退文本、规则校验及会话隔离。decision.py 将 B 的对象和完整问答历史适配到 C。

新版 D 的页面接入了五种结果状态，并复用上一轮识别记录。Identify item 移到手机照片输入区内，结果增加 Why this advice?。超范围名称根据 B 的实际返回值显示。

2026-11-11 的整合验证包含 160 项 pytest、11 项 D 后端测试，以及桌面、390 和 320 像素宽度下的浏览器交互。真实视觉 API 用两张开发照片联调，其中塑料瓶在脚本补充材质后给出建议，纸巾直接得到建议。这些记录用于说明链路运行情况。

本包包含 20 张开发图和 60 张正式测试图。正式集的结构化观察回放用于规则与追问回归，最终版本的正式视觉对照实验后续记录。实际相机权限和现场照片效果还需在展示设备上检查。
